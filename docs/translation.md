The canonical language for this codebase is english.

Every ship has both an English epithet and a Chinese conventional name. Use the epithet in English (`The Tigress`) and the conventional name in Chinese (`顧大嫂`). The Chinese name is the source figure's conventional name, not a translation of the epithet. A ship's star is separate metadata, not its name in either language.

A ship's main title is its pennant, its conventional name, and its epithet together: `EF-147 顧大嫂 The Tigress`. Use that where a ship is formally identified; the language of the surrounding text decides which name a shorter reference uses.

Generated ship text uses epithets only: a ship never calls itself or another ship by a conventional name, in any language. That limit applies to what ships say, not to how the interface identifies them.
